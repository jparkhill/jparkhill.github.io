# Calendar organizer

## Workflow
1. Load the calendar data provided (ICS/JSON/pasted).
2. Detect conflicts and days that are over-booked.
3. Propose a plan that protects deep-work blocks.
4. Draft invitation text for anything that needs one.
5. Save durable preferences (e.g. "no meetings before 10am") to memory.

Never create or modify real events without approval.
